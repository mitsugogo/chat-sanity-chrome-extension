# ChatSanity

YouTube Live Chat向けのManifest V3 Chrome拡張です。日本語チャットをルールベースで分類し、必要な場合だけChrome内蔵AI（Gemini Nano / Prompt API）またはLM Studioへ、曖昧なコメントとルール未一致から抽選された少数のコメントを送ります。処理は端末内で完結し、クラウドAIは使用しません。

## 開発

```powershell
pnpm install
pnpm dev
```

Chromeの `chrome://extensions` で「デベロッパー モード」を有効にし、WXTが生成した `.output/chrome-mv3-dev` を「パッケージ化されていない拡張機能を読み込む」から選択します。

本番用ビルドは次のコマンドで `.output/chrome-mv3` に生成されます。

```powershell
pnpm build
```

## ローカルAI

詳細設定の「AIプロバイダー」では、Chrome内蔵AIとLM Studioの優先順位を選べます。既定の「自動」はChrome内蔵AIを優先し、利用できない場合だけLM Studioへフォールバックし、どちらも利用できない場合はルール結果を使用します。「Chrome 内蔵AI」「LM Studio」「使用しない」も選択できます。

Chrome内蔵AIはChrome 138以降の拡張機能向けPrompt APIをfeature detectionして使用します。`downloadable`または`downloading`はライブチャット中の利用可能状態とはみなさず、勝手にモデル取得を開始しません。詳細設定の「Chrome AIを準備する」を押したユーザー操作からだけモデルを取得します。分類ではsystem promptだけのbase sessionを遅延作成し、batchごとに`clone()`したsessionを使って破棄します。Service Worker再起動時はsessionを再生成します。

## LM Studio

1. LM Studioでモデルを読み込み、Developer画面からローカルサーバーを開始します。
2. ChatSanityの詳細設定で「AIプロバイダー」の「LM Studio」を選択します。
3. ローカル接続の権限を許可し、モデルを選択して設定を保存します。

初期接続先は `http://127.0.0.1:1234` です。コメント本文はlocalhost以外へ送信せず、履歴も永続保存しません。LM Studioが利用できない場合はルールベース判定へ戻ります。

### 調整できる項目

- **AI応答の待ち時間**: 既定10秒、1〜60秒。チャットは500msでルール結果を表示し、後からAIが成功した場合に更新します。
- **応答形式**: JSON Schemaが既定です。モデルが対応しない場合はJSON Object、またはテキスト形式を選べます。どの形式でも返されたJSONのID・カテゴリ・スコアを検証し、不正な結果は適用しません。
- **最大件数**: 200msごとに最大1〜20件。Chrome内蔵AIへは内部で最大8件に再分割し、LM Studioは最大20件を維持します。同時実行は1バッチ、待機は最大100件とし、混雑時はルール結果で表示します。
- **AI対象スコア**: 0.35〜0.80の範囲内で下限・上限を調整できます。無効にしたカテゴリや重みはAI判定にも反映します。
- **未判定コメントの再確認**: ルール未一致かつ0点のコメントは、既定3%を基礎に初見の本文・婉曲的な催促などで確率を補正し、一部だけZero-score Auditとして送信します。最大12件/分・同時20件に制限し、弱いシグナルだけでは表示を変えません。設定画面で無効化できます。
- **文脈補正**: 同一投稿者の直近60秒のリスク投稿、直近のリスク投稿、チャット全体の対立度だけを補助情報としてローカルAIへ渡します。投稿者名、メンバー状態、DOMは渡しません。対立度は判定スコアを少し補正するだけで、全コメントを一括で隠しません。
- **閲覧中の一時ルール**: 強い問題と判定された同文を再利用し、異なる3本文で一致し、文節単独でも同じカテゴリの高スコアをAIが返した場合に一時ルールへ昇格します。現在のチャットフレーム内だけで使い、再読み込み・設定変更でリセットします。コメントや学習結果を永続保存しません。
- **キャッシュ**: `providerId + promptVersion + 正規化本文`ごとにAI結果を最大10分だけ再利用します。Provider・prompt・設定変更またはタブ終了時に破棄します。
- **繰り返し投稿者**: 同じ配信でぼかし・非表示が続いたユーザーは、そのセッション内でスコアを上げて非表示側へ倒します。閾値に達したチャンネルは詳細設定の「非表示ユーザー」へ記録し、他の配信でも非表示にします。表示したい場合はホワイトリストへ移せます。自分の投稿は常に表示（0.00）です。

カテゴリは指示・指示厨、責任追及・戦犯扱い、人格・能力攻撃、比較・対立煽り、自治・コメント欄の喧嘩、不満・愚痴、鳩・別視点、ネタバレに分かれ、カテゴリごとに「スコアに従う」「表示」「薄く表示」「ぼかす」「非表示」を選べます。`非表示`は元ノードを削除せず、`ぼかし`をアイコンと発言者IDまで広げた表示です。本文をクリックすると一時的に原文を確認できます。

「デバッグモード」をONにすると、チャットの対応済み行へ薄いスコアを付け、AI判定中には「AI検閲中」を表示します。詳細設定のデバッグ履歴では、本文・カテゴリ・スコア・判定元・対応理由を最大200件確認でき、Zero-score Audit由来の判定には監査確率と抽選値も残します。履歴はメモリ内だけに保持し、デバッグOFF、設定変更、タブ終了で消去します。

### Flow Chat for YouTube Live連携

詳細設定の「Flow Chat連携」をONにすると、Flow Chat for YouTube Liveが動画上へ流す前に、ChatSanityで`ぼかし`相当以上と判定したコメントを除外できます。連携はYouTubeチャットDOMの`ylcfr-*`クラスだけを使い、通信、ネットワークProxy、`chrome.management`権限は追加しません。Flow Chatが入っていない場合も通常のYouTubeフィルターはそのまま動作します。

Flow側の基準は既定で現在のプリセットの「ぼかし」閾値です。「非表示のみ」またはカスタムスコアも選べます。連携を有効にすると、Flow Chatが観測する`#items`直下の要素（解析対象外のmembership・paid・placeholderを含む）も、解析できない場合は即時に許可として確定します。判定はルールと文脈スコアを使って750ms以内に完了し、遅れて届くLM Studio結果はFlow側へ再適用しません。デバッグモードでは受信数、分類数、除外数、許可数、キャッシュ、タイムアウト、エラー、平均・最大レイテンシを確認できます。

Flow Chat判定の高速LLM経路は初期状態で無効です。Flow Chatの待機時間を伸ばさず、ローカルAIがない環境でも同じ連携が成立する構成を優先しています。

診断プレビューは現在の編集内容で本番と同じAI結果合成を試します。AIが失敗した場合はルール結果と失敗理由を表示します。単発の診断では実チャットの連投履歴や一時学習は再現しません。

一時学習の根拠は、ルールスコアがAI対象の曖昧域に入ったコメントへのAI判定です。文節単独の確認もこの条件に従います。Zero-score Auditの結果は正規化本文のキャッシュにだけ保存し、自動的な一時ルール生成には使いません。未検出の全コメントをAIで探索する機能ではなく、閲覧時間だけで精度向上を保証するものではありません。

日本語の命令形・煽り・皮肉・鳩・比較・杞憂・ネタバレは表記揺れを正規化して判定します。短い応援や一般的な質問との誤検出を抑えていますが、文脈のない短文を完全に分類できるものではありません。通常プリセットでは指示などのカテゴリが無効なので、箱ゲー・完全平和かカテゴリ設定で調整してください。実データから抽出した評価用フィクスチャは匿名化して `tests/fixtures/chat-classification.json` に含め、元のチャットログや投稿者IDはリポジトリへ含めません。

LLMなしでも、対象検出（人物・役割／ゲーム内対象）、命令形、責任追及、能力攻撃、比較、コメント欄への介入、不満、疑問形、笑い・応援の安全文脈を小さなfeatureとして組み合わせてスコア化します。人物を指さない「武器が使えない」や、応援の「ナイス指示」は強い攻撃判定になりません。曖昧な0.35〜0.80は、LLMがない場合は文脈補正を加えても原則allowを維持します。

ルールには`BACKSEAT_001`や`BLAME_FEATURE_001`のようなIDが付き、デバッグ履歴で理由・特徴・文脈補正と一緒に確認できます。`tests/evaluation/`には、匿名化したpositive、hard-negative、ambiguous、contextのフィクスチャと、precision／recall／false-positive-rateを確認するテストを置いています。元の`BMoPMmtKosQ`チャット全体は保存しません。

## 検証

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm format:check
pnpm build
```

対象画面はYouTubeのライブチャット、ポップアウトチャット、アーカイブのチャットリプレイです。通常動画のコメント欄は対象外です。
