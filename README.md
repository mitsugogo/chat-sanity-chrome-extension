# ChatSanity

YouTube Live Chat向けのManifest V3 Chrome拡張です。日本語チャットをルールベースで分類し、必要な場合だけLM StudioのローカルLLMへ曖昧なコメントを送ります。

## 開発

```powershell
pnpm install
pnpm dev
```

Chromeの `chrome://extensions` で「デベロッパー モード」を有効にし、WXTが生成した `.output/chrome-mv3-dev` を「パッケージ化されていない拡張機能を読み込む」から選択します。

本番用ビルドは次のコマンドで `.output/chrome-mv3` に生成されます。

```powershell
pnpm build
```

## LM Studio

1. LM Studioでモデルを読み込み、Developer画面からローカルサーバーを開始します。
2. ChatSanityの詳細設定で「LM Studioを使用する」を有効にします。
3. ローカル接続の権限を許可し、モデルを選択して設定を保存します。

初期接続先は `http://127.0.0.1:1234` です。コメント本文はlocalhost以外へ送信せず、履歴も永続保存しません。LM Studioが利用できない場合はルールベース判定へ戻ります。

### 調整できる項目

- **AI応答の待ち時間**: 既定10秒、1〜60秒。チャットは500msでルール結果を表示し、後からAIが成功した場合に更新します。
- **応答形式**: JSON Schemaが既定です。モデルが対応しない場合はJSON Object、またはテキスト形式を選べます。どの形式でも返されたJSONのID・カテゴリ・スコアを検証し、不正な結果は適用しません。
- **最大件数**: 200msごとに最大1〜20件。遅いモデルでは件数を減らしてください。同時実行は1バッチ、待機は最大100件とし、混雑時はルール結果で表示します。
- **AI対象スコア**: 0.35〜0.80の範囲内で下限・上限を調整できます。無効にしたカテゴリや重みはAI判定にも反映します。
- **文脈補正**: 同一投稿者の直近60秒のリスク投稿、直近のリスク投稿、チャット全体の対立度だけを補助情報としてローカルAIへ渡します。投稿者名、メンバー状態、DOMは渡しません。対立度は判定スコアを少し補正するだけで、全コメントを一括で隠しません。
- **閲覧中の一時ルール**: 強い問題と判定された同文を再利用し、異なる3本文で一致し、文節単独でも同じカテゴリの高スコアをAIが返した場合に一時ルールへ昇格します。現在のチャットフレーム内だけで使い、再読み込み・設定変更でリセットします。コメントや学習結果を永続保存しません。
- **キャッシュ**: 正規化した本文ごとにLM Studioの結果を最大10分だけ再利用します。キャッシュは最大500件で、タブ終了時に破棄します。

カテゴリは指示・指示厨、責任追及・戦犯扱い、人格・能力攻撃、比較・対立煽り、自治・コメント欄の喧嘩、不満・愚痴、鳩・別視点、ネタバレに分かれ、カテゴリごとに「スコアに従う」「表示」「薄く表示」「ぼかす」「非表示」を選べます。`非表示`は元ノードを削除せず、`ぼかし`をアイコンと発言者IDまで広げた表示です。本文をクリックすると一時的に原文を確認できます。

「デバッグモード」をONにすると、チャットの対応済み行へ薄いスコアを付け、AI判定中には「AI検閲中」を表示します。詳細設定のデバッグ履歴では、本文・カテゴリ・スコア・判定元・対応理由を最大200件確認できます。履歴はメモリ内だけに保持し、デバッグOFF、設定変更、タブ終了で消去します。

診断プレビューは現在の編集内容で本番と同じAI結果合成を試します。AIが失敗した場合はルール結果と失敗理由を表示します。単発の診断では実チャットの連投履歴や一時学習は再現しません。

一時学習の根拠は、ルールスコアがAI対象の曖昧域に入ったコメントへのAI判定です。文節単独の確認もこの条件に従います。未検出の全コメントをAIで探索する機能ではなく、閲覧時間だけで精度向上を保証するものではありません。

日本語の命令形・煽り・皮肉・鳩・比較・杞憂・ネタバレは表記揺れを正規化して判定します。短い応援や一般的な質問との誤検出を抑えていますが、文脈のない短文を完全に分類できるものではありません。通常プリセットでは指示などのカテゴリが無効なので、箱ゲー・完全平和かカテゴリ設定で調整してください。実データから抽出した評価用フィクスチャは匿名化して `tests/fixtures/chat-classification.json` に含め、元のチャットログや投稿者IDはリポジトリへ含めません。

## 検証

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm format:check
pnpm build
```

対象画面はYouTubeのライブチャット、ポップアウトチャット、アーカイブのチャットリプレイです。通常動画のコメント欄は対象外です。
